# 🍌 banana

A collection of freely licensed banana images: bananas, plantains, banana plants, flowers, leaves and banana dishes.

- `images/<topic>/` holds the images, sorted into 95 folders such as `banana-bread`, `banana-tree`, `plantains` and `banana-split`, plus folders for banana in other languages (`banane`, `pisang`, `banana-japanese`, `xiangjiao-chinese`, ...). Files are named after their titles, for example `banana-bread/one-bowl-banana-bread-with-cacao-nibs-3.jpg`.
- `CREDITS.csv` lists the title, creator, license and source page for every image.

Every image is public domain or under a Creative Commons license. Some licenses are NonCommercial (NC) or NoDerivatives (ND), and most require attribution. Check `CREDITS.csv` before you reuse an image.

Sources: [Openverse](https://openverse.org) and [Wikimedia Commons](https://commons.wikimedia.org).
